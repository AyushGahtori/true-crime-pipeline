# True-Crime Documentary Pipeline: Architecture & Engineering Blueprint (v3)

A single-host, policy-hardened hybrid AI production blueprint designed to produce up to **10 twenty-minute (1,200-second) stylized true-crime documentaries per month**—validated first via a **genuine Milestone M0.5 Minimal End-to-End Thin Vertical Slice** before full 12-motif / 3-conveyor expansion—using **`gemini-omni-1.2-flash` via the official Gemini Interactions API (`~$8.00–$10.40/ep` @ `720p`, `<= 10` clips / `80s` max, `$135/mo` total autonomous compute cap) + DeepSeek V4.1 Flash/V4-Pro (`~$0.75–$1.90/ep`) + Gemini TTS/ASR (`~$0.45/ep`)**, with a separate optional Enterprise Vertex adapter and an optional manual Batch Desk UI.

> **Repository Scope Notice:** This directory contains the hardened v3 architecture specification, executable SQLite schema + 12-scenario test harness (`schema/pipeline.sql`, `schema/schema-test.js`), Mermaid diagram atlas, cited research notes, and 200-task two-developer implementation plan. Runtime application code is built by following [IMPLEMENTATION_TASKS.md](IMPLEMENTATION_TASKS.md) starting with M0 Contract Freeze and M0.5 Thin Vertical Slice.

## The Architecture In One Paragraph

A deterministic **Python Sole-Writer Orchestrator** (`pipeline.db` v3 in SQLite WAL mode, pinned **`SQLite >= 3.51.3`** on local host storage) drives a 6-agent pipeline, a loopback-locked FastAPI control plane (`127.0.0.1` + `X-Local-Auth-Token`), a **mandatory 5-gate human release approval boundary**, and a post-publish YouTube Analytics calibration loop. **Agent 1 v3** mines zero-search YouTube watchlists (mutually exclusive Saturation Index buckets, 90-day `>200K` instant kills, mandatory non-null 30-day YouTube API full-field retention purge, authorized metadata/comment leads only—no unsupported third-party caption scraping) plus MuckRock/CourtListener Track B feeds under a Clean-Room Seed Firewall; **Agent 2** enforces INSERT+UPDATE appellate disposition guards with automatic downstream legal-hold quarantine (`QUARANTINED_LEGAL_HOLD`), explicit human-verified third-party anonymization (`NOT_STARTED -> IN_REVIEW -> APPROVED`), a source-tiered Temporal Fact Ledger, and early **clearly labeled illustrative 2K scene plates** (`still_assets.is_illustrative_reconstruction = 1`) + external-margin `10x10` anchor locking (`DRAFT -> IN_REVIEW -> LOCKED`); **Agent 3** enforces component-level rights provenance (narrowing 17 U.S.C. § 105 strictly to federal-employee works and blocking third-party FOIA attachments), music-gated Demucs paired with honest `asr_hypothesis_disagreement` (and offline labeled-corpus WER), visual + spoken PII scrubbing, and risk-control linting; a **Voice-First Segmented Timeline** (`voice_segments` non-overlap triggers + `NarrationSegments` + `FoiaAudioSlots` + `TwistPads`) aligns narration; **Agent 4** compiles a conflict-free `ProductionManifest` (`13.0m Code/FOIA / 5.67m 2K Illustrative / 1.33m Omni Hero`, `max_hero_clips = 10`) using the single authoritative `MOTIF_REGISTRY_V1`; **Agent 5** renders `@tc/render_catalog` 2D vector scenes (`6 fps` JS vertex-jitter, zero `<feTurbulence>`), Python `crime_scene_2k` Lanczos pan/zoom + screen-space callouts + mandatory `ILLUSTRATIVE RECONSTRUCTION` watermark, and crash-safe `gemini-omni-1.2-flash` Interactions API clips backed by durable SQLite `budget_reservations`, `UNIQUE(episode_id, scene_id)`, `UNKNOWN_RECONCILE`, and fail-closed Vision QA (`PENDING_MANUAL_SPOT_CHECK`); and **Agent 6** runs per-track pre-normalization -> `linear=true` `-14.0 LUFS` mastering, single continuous non-FOIA grain, Safe-Zone verification, `2x2` Vision QA, and **5-gate human release sign-off** before `ready_to_upload/` promotion.
