# Open Design Questions & Resolved Architecture Decisions (v4 · November 23, 2026)

| Topic | Resolved Decision (v4) | Rationale |
|---|---|---|
| **Offline-First Tests & Live Check (`F-01`)** | **100% offline zero-spend transport mocks (`purpose='OFFLINE_TEST' -> $0` DB guard + socket blocker + scrubbed API keys)** across all worktree/CI tasks (`001–199`); **1 bounded live check (`<= $2.00`) strictly post-integration** (`Task 200`). | Prevents accidental billing during automated agent/CI runs while keeping connectivity verification bounded and deliberate. |
| **Global Across-Providers Cap (`F-02`)** | Authoritative **`monthly_budget_ledger` + `provider_spend_reservations`** inside `pipeline.db` caps **`ALL_PROVIDERS` at `$135/mo`** alongside per-provider caps (`deepseek_chat` `$38/mo` @ `0%` cache) and per-episode video `$10.40` cap. | Prevents independent providers or lagging `telemetry.db` rows from breaching the stated `$135/mo` monthly ceiling. |
| **ASR Size & Word-Timing (`F-03`)** | **Local WhisperX forced alignment** is the sole owner of millisecond word timestamps; optional cloud ASR slices raw audio to `16 kHz` mono FLAC `<= 90s / <= 4 MiB` (`< 8 MiB / 120s` limit). | DeepSeek Speech-to-Text caps files at `8 MiB / 120s` and does not emit word-level timestamps; `48 kHz` stereo WAV exceeds `8 MiB` in `< 1` minute. |
| **Canonical v4 Spec Alignment (`F-04`)** | Every file and all 200 tasks reconciled strictly to **`schema_version = 4`**, **`gemini-omni-1.2-flash`**, **`max_hero_clips = 10` (`80s`)**, and **`TEXT_TO_VIDEO` | `FIRST_FRAME` | `FIRST_AND_LAST_FRAME`**. | Eliminates integration breaks caused by mixed v2/v3 task instructions across worktrees. |
| **Versioned `ScenePlan` & `craft_rubric.yaml` (`F-05`, `F-06`)** | Explicit **`scene_plans` SQLite contract** (`Plan -> Voice -> Create -> Edit`) + invalidation trigger on narration edits + modular `craft_rubric.yaml` (`<= 150 lines`; `"interactive"` = engaging visual pacing). | Replaces opaque JSON and prevents mismatched narration/assets or 4,000-line brittle prompts. |
| **Wave-Ordered Merge Runbook (`F-07`)** | Sequential waves (`W1-A..W5-A`, `W1-B..W4-B`) with pinned base commits, explicit shared-file Contract Bump PRs, sequential SQL migrations, and `git revert -m 1` rollback commands. | Prevents stale branch bases and schema divergence across 2 parallel ~100-task tracks. |
| **Blueprint Scope & Reproducibility (`F-08`)** | Explicitly labeled as **Architecture & Schema v4 Blueprint**; dual no-cache vs cached budgets; `<data>` tool-less sanitization + adversarial tests; `total_input_tokens >= cached_input_tokens` DB CHECK. | Ensures complete honesty about blueprint vs runtime code, cache variability, and injection resistance. |
