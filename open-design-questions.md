# Open Design Questions & Resolved Architecture Decisions (v3)

This ledger tracks every architectural decision updated through **November 23, 2026** (including all 22 findings `F-01`–`F-22` from the full architecture, schema, legal, and provider audit).

| Topic | Resolved Decision (v3) | Rationale |
|---|---|---|
| **Primary Video Provider (`F-01`)** | **`gemini-omni-1.2-flash` via official Gemini Interactions API (`google-genai >= 2.30.1`)** is Primary Default. `VERTEX_VEO_ENTERPRISE` and `HUMAN_BATCH_DESK` are separate, non-interchangeable adapters. | Veo 3.1 Preview endpoints (including Lite) on the Gemini Developer API shut down on **October 22, 2026**. |
| **Honest Runtime & Monthly Budget (`F-02`)** | **`13.0m Code/FOIA (780s) + 5.67m 2K Illustrative Stills (340s) + 1.33m Hero Video (80s = <=10 clips)`**; `$8.00` base / **`$10.40` hard cap/ep** (`$135/mo` cap @ 10 eps); single source of truth in `providers.yaml`. | At Omni 1.2 Flash's token-billed `~$0.07–$0.10/sec` 720p rate (budgeted conservatively at `$0.10/sec`), 120s would breach `$90/mo`; 80s + `$135/mo` is honest and eliminates the 15-vs-16 clip contradiction. |
| **Legal Disposition & Anonymization (`F-03`, `F-04`)** | Guard `cases` on **both INSERT and UPDATE** + auto-quarantine downstream episodes (`QUARANTINED_LEGAL_HOLD`) & revoke approvals; replace default-`1` flags with explicit `NOT_STARTED -> IN_REVIEW -> APPROVED` and `DRAFT -> IN_REVIEW -> LOCKED` state machines. | Prevents silent stale approvals when convictions reverse and prevents unreviewed data from appearing anonymized/locked by default. |
| **Generated Art vs. Evidence (`F-05`)** | Every generated 2K still carries `is_illustrative_reconstruction = 1` + visible **`ILLUSTRATIVE RECONSTRUCTION — NOT CRIME SCENE PHOTO`** label; claims cite primary `fact_ledger` records only. | Prevents viewers from mistaking AI-generated room layouts for verified historical crime-scene evidence. |
| **Human Release Gate & Takedown (`F-06`)** | Mandatory 5-gate human sign-off (`release_approvals`: `FACTUAL_ACCURACY`, `PRIVACY_PII`, `SOURCE_RIGHTS`, `SYNTHETIC_DISCLOSURE`, `ILLUSTRATIVE_LABELING`) enforced by `trg_episode_release_gate` + 24h post-publish correction/takedown SOP. | Automated checks are fallible risk controls; an accountable named reviewer must approve legal, privacy, rights, and synthetic-content risks before release. |
| **Crash Idempotency & Durable USD Cap (`F-10`, `F-18`)** | Persist `UNIQUE(episode_id, scene_id)`, `idempotency_key`, `provider_operation_id`, `SUBMITTING`/`RUNNING`/`UNKNOWN_RECONCILE` states, and `budget_reservations` (`trg_budget_cap_guard`) directly in `pipeline.db` (NEVER async `telemetry.db`). Vision QA outages fail **closed** (`PENDING_MANUAL_SPOT_CHECK`). | Prevents duplicate paid generations after crashes/timeouts and guarantees hard USD admission control across restarts. |
| **YouTube Data, Analytics & Retention (`F-11`, `F-12`, `F-20`)** | Remove unsupported third-party `captions.download` fallback and fabricated `videos.list` monetization fields (`adsense_status` defaults to `'UNKNOWN'`, populated via Studio CSV / manual entry); enforce non-null 30-day `yt_ttl_expires_at` purging ALL YT-derived fields. | Aligns strictly with YouTube Data API v3, YouTube Analytics API, and YouTube API Services Developer Policies. |
| **Authoritative 4-Motif Slice & M0.5 (`F-16`, `F-17`)** | Single `motif_registry` (`StickmanStage`, `AudioEvidenceCard`, `RedactedDocReveal`, `FoiaFootageFrame`; `Illustrative2KPanZoom` owned solely by `crime_scene_2k`); run genuine **Milestone M0.5 Minimal End-to-End Slice** (including live Omni sandbox check) BEFORE building full 12 motifs or Batch Desk UI. | Eliminates 3-way naming drift and validates real provider contracts, costs, and rendering early. |
| **Security & SQLite Pin (`F-19`, `F-22`)** | Loopback-only FastAPI (`127.0.0.1` + `X-Local-Auth-Token` + CORS + upload containment + `audit_log`); pin **`SQLite >= 3.51.3`** on local host storage + `VACUUM INTO` hot backups + disk watermarks. | Hardens local control plane and avoids SQLite WAL-reset bug and network-share WAL corruption. |
| **Open Operational Question (To Verify in M0.5)** | Confirm actual observed `gemini-omni-1.2-flash` `720p` per-second invoice cost and latency in a bounded `<= $2.00` live sandbox run (`M0.5`) and update `providers.yaml` accordingly. | Token-billed video pricing (`~$0.07–$0.10/sec`) varies with prompt/reference density; live measurement replaces estimates before production spend. |
