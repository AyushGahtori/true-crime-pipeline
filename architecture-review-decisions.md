# Architecture Review Decisions & Audit Remediation Matrix (v3)

Every structural bug, retired provider endpoint, schema vulnerability, legal/rights gap, and strategy contradiction identified across Audit v1 and Audit v2 (`F-01` through `F-22`, November 23, 2026) has an explicit deterministic fix:

| Audit ID / Area | Failure Mode | Concrete Engineering Fix (v3) | Observable Verification Check |
|---|---|---|---|
| **F-01 · Retired Video API** | Veo 3.1 Lite preview on Gemini Developer API shut down Oct 22, 2026. | Migrated primary default to **`gemini-omni-1.2-flash`** via **Gemini Interactions API** (`google-genai >= 2.30.1` + Files API); isolated `VERTEX_VEO_ENTERPRISE` and `HUMAN_BATCH_DESK` as distinct non-interchangeable adapters. | `meta.primary_video_model = 'gemini-omni-1.2-flash'`; M0.5 bounded live sandbox contract check. |
| **F-02 · Economics & Clip Cap** | `$60` Veo budget breaks at Omni `~$0.10/sec` 720p; 15-vs-16 clip count contradiction. | Single source of truth in `providers.yaml` + DB: **`max_hero_clips = 10`**, **`max_hero_duration_sec = 80s`** (`1.33m` Hero + `5.67m` 2K + `13.0m` Code/FOIA); `$8.00` base / `$10.40` hard cap (`$135/mo` cap @ 10 eps). | `episodes.video_budget_cap_micro_usd = 10400000` enforced by `trg_budget_cap_guard`. |
| **F-03 · Case Update Guard** | `trg_case_disposition_guard` only fired on `INSERT`, ignoring adverse `UPDATE`s. | Added `trg_case_disposition_guard_update` (`BEFORE UPDATE`) AND `trg_case_disposition_quarantine` (`AFTER UPDATE`) auto-quarantining episodes (`QUARANTINED_LEGAL_HOLD`) and revoking approvals. | `schema-test.js` Scenario #3 verifies `UPDATE` rejection + auto-quarantine + approval revocation. |
| **F-04 · Default-True Flags** | `third_parties_anonymized = 1` & `locked_before_script = 1` defaulted true without work/review. | Replaced with explicit state machines (`NOT_STARTED -> IN_REVIEW -> APPROVED` & `DRAFT -> IN_REVIEW -> LOCKED`) requiring reviewer ID, timestamp, and artifact SHA-256. | `schema-test.js` Scenario #4 blocks unreviewed `APPROVED`/`LOCKED` flips. |
| **F-05 · Illustrative Labeling** | Generated 2K room art looked like verified spatial crime-scene evidence. | Mandatory `still_assets.is_illustrative_reconstruction = 1` + visible **`ILLUSTRATIVE RECONSTRUCTION — NOT CRIME SCENE PHOTO`** label; factual claims anchored solely to primary `fact_ledger` docs. | `still_assets` CHECK + human `ILLUSTRATIVE_LABELING` sign-off gate. |
| **F-06 · Human Sign-Off Gate** | No mandatory factual, privacy, rights, or post-publish takedown approval gate. | Added `release_approvals` table (5 mandatory gates) + `trg_episode_release_gate` blocking `READY_TO_UPLOAD`/`PUBLISHED` + documented 24h correction/takedown SOP. | `schema-test.js` Scenario #5 blocks unsigned export & fails closed on `PENDING_MANUAL_SPOT_CHECK`. |
| **F-07 · T2V Job Schema** | `flow_jobs.start_frame_png NOT NULL` broke `TEXT_TO_VIDEO` jobs. | Added `prompt_mode` (`TEXT_TO_VIDEO`, `FIRST_FRAME`, `FIRST_AND_LAST_FRAME`), nullable frames, and strict mode-specific `CHECK` (including `<= 10s` cap on 2-frame Omni transitions). | `schema-test.js` Scenario #6 verifies all 3 prompt modes + duration check. |
| **F-08 · Daily Credit Refill/Lock** | SQL query never refilled `daily_credits_left` and failed to lock properly. | Replaced with `atomic_refill_and_reserve_daily_account_credits` + `refund_daily_account_credits` enforcing `24h+5m` lock & exact-boundary refill. | `schema-test.js` Scenario #7 verifies `reset - 1ms` rejection & `reset` atomic refill. |
| **F-09 · Timeline & Asset Refs** | Missing FKs, unvalidated `grid_cell`, nullable media, and overlapping intervals. | Added `still_assets` FK, `grid_cell` `A1..J10` `GLOB` check, kind-specific `voice_segments` checks, `BEFORE INSERT/UPDATE` non-overlap triggers on `voice_segments`/`scenes`, and `timeline_validated_sha256`. | `schema-test.js` Scenarios #4 & #8 verify overlap rejection & kind constraints. |
| **F-10 & F-18 · Crash Idempotency & USD Cap** | No `UNIQUE(episode_id, scene_id)`, unknown state, or durable USD budget reservation. | Added `UNIQUE(episode_id, scene_id)`, `idempotency_key`, `provider_operation_id` in `pipeline.db`, `SUBMITTING`/`RUNNING`/`UNKNOWN_RECONCILE` states, and `budget_reservations` + `trg_budget_cap_guard`. | `schema-test.js` Scenario #9 verifies duplicate block, `UNKNOWN_HOLD`, and hard USD cap breach. |
| **F-11 · YouTube Transcripts** | `captions.download` requires video edit rights (doesn't work on arbitrary public videos). | Removed unsupported public transcript download fallback; Track A uses strictly authorized metadata/comment leads (`LEAD_ONLY`), never factual evidence. | Updated `scout-and-saturation.md` & `Task 023`. |
| **F-12 · `videos.list` Monetization** | `videos.list` has no `monetizationDetails` or yellow-icon field. | Removed fabricated API claim; `episode_analytics.adsense_status` defaults to `'UNKNOWN'` with explicit `adsense_source` (`STUDIO_CSV_EXPORT` / `MANUAL_CREATOR_ENTRY` / `UNAVAILABLE`). | `schema-test.js` Scenario #10 verifies honest `UNKNOWN`/`UNAVAILABLE`/nullable CTR defaults. |
| **F-13 · Policy Date & AdSense Gate** | Cited July 2026 instead of July 2025 YPP clarification; treated green AdSense as deterministic gate. | Corrected to **July 2025 YPP policy clarification** with official URL; framed checks as risk controls + human monitoring (never guaranteed monetization). | Updated `roadmap.md` & `research/youtube-2026-policy-and-adsense.md`. |
| **F-14 · Overbroad §105 Rule** | Treated all federal FOIA releases as blanket public domain. | Narrowed `US_FED_EMPLOYEE_17USC105` strictly to federal-employee works; added per-asset `creator_entity`, `rights_holder`, `license_basis`, `contains_third_party_attach`, `rights_review_status`. | `schema-test.js` Scenario #11 blocks approving `RESTRICTED_NO_REUSE` assets. |
| **F-15 · Misnamed `delta_WER`** | Comparing two ASR hypotheses is disagreement, not WER. | Renamed production column/metric to `asr_hypothesis_disagreement` (triggering `human_audio_review_required = 1`), reserving true `labeled_corpus_wer` strictly for manually verified reference sets. | `schema-test.js` Scenario #11 + updated `Task 047` & audio research note. |
| **F-16 · 4-Motif Naming Drift** | Three conflicting 4-motif lists + ambiguous `CrimeScenePanZoom` ownership. | Froze single `motif_registry` table (`StickmanStage`, `AudioEvidenceCard`, `RedactedDocReveal`, `FoiaFootageFrame`) + assigned `Illustrative2KPanZoom` solely to Python `crime_scene_2k`. | `schema-test.js` Scenario #2 verifies `is_mvp_4 = 1` count == 4 across unified registry. |
| **F-17 · Late Vertical Slice** | Early vertical slice (`Task 193`) depended on full Part 1 & Part 2 certification. | Promoted genuine **Milestone M0.5 Minimal End-to-End Thin Vertical Slice** immediately after M0 Contract Freeze (1 case, 1 illustrative plate, 4 MVP motifs, 1 live Omni 1.2 Flash call, human sign-off). | Updated `roadmap.md` & `IMPLEMENTATION_TASKS.md` dependency graph (`Tasks 189, 193`). |
| **F-19 · FastAPI Security Boundary** | Unspecified network bind, auth, CORS, CSRF, upload containment, and audit logging. | Locked loopback-only `127.0.0.1`, per-session `X-Local-Auth-Token` (`0600`), localhost CORS, upload size/path containment, and `audit_log` table. | Updated `flow-hybrid-and-batch-desk.md`, `database-and-state-design.md`, and `Task 177`. |
| **F-20 · YouTube Retention Scope** | Nullable TTL and partial purge kept derived YT fields past 30 days. | Enforced `CHECK (track != 'TRACK_A_OUTLIER' OR yt_ttl_expires_at IS NOT NULL)` and updated `purge_expired_yt_api_records` to clear ALL YT-derived fields (`views_count`, `outlier_ratio`, `seed_packet_json`, `raw_yt_payload_json`). | `schema-test.js` Scenario #10 rejects NULL TTL & verifies full-field purge. |
| **F-21 · Unverified Research Claims** | Uncited `"50x"`, `"1–3s/frame"`, `"71.7%"` treated as proven facts. | Added source URLs + audit date (`2026-11-23`) for external claims and explicitly labeled unmeasured perf numbers as **Hypotheses / Design Targets** pending reproducible local benchmarks. | Updated `research/README.md` & all `research/*.md` notes. |
| **F-22 · SQLite Runtime Pin** | Missing `SQLite >= 3.51.3` pin, local-disk WAL check, and backup/restore lifecycle. | Pinned `min_sqlite_version = 3.51.3`, startup local-filesystem check (no SMB/NFS), and `VACUUM INTO` hot backup/restore + disk-watermark lifecycle. | `meta` pin + updated `database-and-state-design.md` & `Tasks 005, 177`. |
